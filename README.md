# スーパーメガラッキーボックス ビンゴカードサポート

謎解き公演「はろなぞ4」で、各チームが使う**ビンゴカードの管理アプリ**です。
カード・トークン（雷・月・星）・得点・操作履歴を、タブレット上で管理します。

## 特徴

- **スタンドアローン動作**: アプリ全体がブラウザ内で動きます。ゲームサーバー・チーム間の通信は不要です。
  - 一度開いた後は**ネットワークがなくても起動・操作できます**（PWA）。
  - 1台＝1チーム。各端末の状態は完全に独立しています。
- **自動保存とレジューム**: 操作のたびに端末内（`localStorage`）へ保存します。ブラウザの再起動・端末の再起動後も、続きから再開できます。
- **Undo / オールリセット**: 直前の操作を取り消せます（最大50件）。オールリセットで初期化します。
- **公開方法**: GitHub Pages で静的ファイルを配信するだけです（`docs/` フォルダ）。

│       ├── engine.js          #   ゲームロジック + 自動保存

## 開発・動作確認

### 簡易サーバーの起動（普段の開発はこれ）

**`start_dev.bat` をダブルクリック**します。`docs/` フォルダを `http://localhost:8080` で配信する簡易サーバーが起動し、ブラウザが自動で開きます。

- 「簡易サーバー」は、`docs/` の中のファイルをそのままブラウザへ渡すだけの小さなプログラムです（GitHub Pages の代わりを、自分のPCの中だけで動かすイメージ）。インターネットには公開されません。
- 起動したまま、ファイルを編集して保存し、ブラウザを再読み込みすれば変更が反映されます。サーバーの再起動は不要です。
- **止めるとき**は、バッチファイルのウィンドウで `Ctrl+C` を押すか、ウィンドウを閉じます。
- ポートが使用中のときは、別のポートを指定できます: `start_dev.bat 8090`
- バッチファイルを使わない場合のコマンド:

  ```powershell
  .\.venv\Scripts\python.exe -m http.server 8080 --directory docs
  ```

> `docs/index.html` をダブルクリックして `file://` で開くと、Service Worker が動きません（画面自体は動きます）。上の方法で開いてください。

### 変更が反映されないとき

オフライン対応のため、ブラウザは古いファイルを保存して優先的に使います（localhost でも同じです）。

- **`Ctrl+Shift+R`（強制再読み込み）**: その1回だけ、最新のファイルを取り込みます。
- **DevTools（F12）→ Application → Service Workers → 「Bypass for network」にチェック**（おすすめ）: DevTools を開いている間は、通常の再読み込みでも常に最新が表示されます。
- 開発中は `version.js` の更新は不要です。**公開（プッシュ）するときだけ**更新します。

### 開発中の保存データ

- PCの `localhost:8080`、GitHub Pages の公開URL、各タブレットは、**それぞれ別の保存領域**です。開発中の操作が、タブレットの状態に影響することはありません。
- 開発中の状態を初期化したいときは、画面の「オールリセット」を押すか、DevTools の Application → Storage → **Clear site data** を押します。

### 初回セットアップ（テスト・ツールを使う場合のみ）

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

### 自動テスト

JS版エンジンが、旧Flask版（`app.py`）と**まったく同じ応答**を返すか確認します。
約4,000ステップの操作列（ボーナス・コンプリート・統合マス・Undo・リセット・エラー応答、および途中での端末再起動）を比較し、続けて保存データの破損時のふるまいも検証します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run_tests.ps1
```

- 約2〜3分かかります。最後に `RESULT: PASS` と出れば成功です。
- Edge または Chrome が必要です。
- 基準データの再生成を省略する場合は `-SkipGen`（`tests\golden.js` を再利用）。
- `tests\golden.js` は自動生成物なので Git では管理しません（`.gitignore` 済み）。

> `.ps1` ファイルは **UTF-8 BOM付き** で保存してください。BOMがないと Windows PowerShell 5.1 で日本語が文字化けします。

## カード・ルールを変更するとき

- **カードの内容（盤面・ボーナス・ラウンド構成）**: `docs/js/cards.js` を直接編集します。
- **ゲームのルール（ロジック）**: `docs/js/engine.js` を変更します。ルール変更の際は、基準である `app.py` も同じように直し、`run_tests.ps1` で一致を確認してください。
- **画面**: `docs/` 以下だけを編集します。

どの変更でも、**公開前に `docs/js/version.js` の `APP_VERSION` を更新**してください（更新しないと、端末に反映されません）。

## 公開（GitHub Pages）

1. 変更をコミットして GitHub へプッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、**Branch** を公開したいブランチ（本番は `main` 推奨）、フォルダを **`/docs`** にして Save します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

> 無料プランで GitHub Pages を使うには、リポジトリが Public である必要があります。公開されるのはソースとカード内容です。

## イベント運営

### 事前準備（端末ごと・必ずネットに繋いだ状態で）

1. タブレットの Chrome（iPad の場合は Safari）で、公開URLを開きます。
2. 画面下部の**バージョン表示**が、最新の `APP_VERSION` と一致していることを確認します。
3. ブラウザのメニューから**ホーム画面に追加**（Chrome は「アプリをインストール」）します。
4. **機内モードにして**、ホーム画面のアイコンから起動できること、操作できることを確認します。
5. 確認用に操作した場合は、最後に**オールリセット**で初期化します。

### 当日

- 参加者には、**ホーム画面のアイコンからだけ**起動してもらいます。同じ端末でアイコンとブラウザのタブを両方開くと、保存内容が食い違うことがあります。
- ブラウザの「サイトデータの削除」や、シークレットモードは使わないでください（そのチームの状態が消えます）。
- **公演の入れ替え時は、全端末で「オールリセット」** を押します。押した後、カードが0枚・雷4個・得点0になっていることを目視で確認してください。
- 画面下に「保存できません」の警告が出た場合は、保存できていません。再読み込みすると進行状況が消えるため、運営に連絡してください。
- 誤操作や数え間違いは、トークンの `+`/`-` ボタンと Undo で修正できます。

### 公開後に修正を配るとき

1. `docs/js/version.js` の `APP_VERSION` を**手で更新**します（例: `2026.10.06-1` → `2026.10.06-2`）。**更新を忘れると、端末は更新に気づきません。**
2. コミットしてプッシュします。GitHub の **Actions** タブで「pages build and deployment」が緑（成功）になるのを待ちます（通常1〜2分）。
3. 各端末を**ネットに繋いだ状態**でアプリを開くと、画面上部に「新しいバージョンがあります」と出ます。「更新する」を押すと切り替わります（進行状況は保存されたまま引き継がれます）。
4. 画面下部のバージョン表示で、全端末が最新になったことを確認します。

通常の再読み込みでは更新されません。反映されないときは、アプリを完全に終了して開き直してください。ブラウザの「サイトデータの削除」でも更新できますが、**保存中のゲーム状態も消えます**。

**イベント直前の修正は避け、前日までにバージョンを確定してください。**

### 注意

- **公開URLを変えると、保存データはすべて失われます**（保存データはURLごとに分かれます）。リポジトリ名の変更や独自ドメインへの切り替えは、本番前に確定させてください。
- 運営側から、各端末の状態を見ることはできません（チーム間・運営への通信はしない仕様です）。
- 端末が故障した場合、そのチームの状態は復元できません。

## 画面の使い方

1. **カード追加**: ラウンドとカードを選んで「カード追加」。
2. **マーク**: カードのマスをタップして黒く塗ります。行・列がそろうとボーナスが発生します。
3. **ボーナス**:
   - ⚡雷・🌙月・⭐星 は自動でトークンが増えます。
   - 数字ボーナスと「？」ボーナスは、ボーナス欄をタップして「使用済み」の色に切り替えられます。
4. **コンプリート**: カードの全マスが埋まると、下の「コンプリートカード」に移ります（1枚10点）。
5. **得点**: コンプリート×10点 ＋ 未コンプリートカードの黒マス数÷2（切り捨て）。
6. **Undo**: 直前の操作を取り消します（「ビンゴカード」見出しの右と、ボタン欄の2か所）。
7. **オールリセット**: すべて初期状態に戻します（確認ダイアログあり）。
