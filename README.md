# スーパーメガラッキーボックス Webアプリ

戦略系ビンゴゲーム「スーパーメガラッキーボックス」のデジタル版です。

## 概要

- 3×3のビンゴカードを使用した戦略的なビンゴゲーム
- 公演用途で最大10チーム程度の同時アクセスに対応
- 各チームは独立したゲーム状態で進行
- 雷トークンによる数字変更、ボーナス獲得、4ラウンド制のゲームシステム

## 機能

### 実装済み機能
- ✅ ビンゴカード選択・追加機能
- ✅ 数字入力（1-9）とクリック選択
- ✅ 雷トークンによる数字変更機能
- ✅ 盤面クリックによるビンゴ処理
- ✅ Undo/Redo機能
- ✅ マルチユーザー対応（セッション管理）
- ✅ レスポンシブデザイン（スマホ対応）
- ✅ トークン管理（雷・月・星）

### 実装予定機能
- 🔄 列完成時のボーナス手動選択・表示
- 🔄 ボーナス種類ごとの処理分岐
- 🔄 CSVファイルからのビンゴカード読み込み
- 🔄 管理者用全チーム状況閲覧機能
- 🔄 得点計算システム
- 🔄 4ラウンド制の実装

## セットアップ

### 必要な環境
- Python 3.7以上
- Flask 2.3.3

### インストール手順

1. 依存関係をインストール:
```bash
pip install -r requirements.txt
```

2. アプリケーションを起動:
```bash
python app.py
```

3. ブラウザで http://localhost:5001 にアクセス（同一PC上）

### 外部公開（イベント用）

ngrokを使用して外部からアクセス可能にできます：

```bash
# ngrokをインストール（初回のみ）
# https://ngrok.com/ からダウンロード

# 外部公開（Flaskは5001番ポートで稼働）
ngrok http 5001
```

### 運用マニュアル（イベント想定）

- **準備**  
  - 会場PCに Python 3.9 以上と必要ライブラリをインストール。  
  - このリポジトリを取得し `python app.py` で Flask サーバーを起動（`http://localhost:5001`）。  
  - Windows のスリープ/省電力を無効化し、自動更新がイベント時間外に実行されるよう調整。
- **ngrok トンネル**  
  - 別ターミナルで `ngrok http 5001` を実行し、表示された `https://*.ngrok-free.app` を参加者へ共有。  
  - 無料プランでは約8時間でセッションが再接続されるため、トンネル状態をダッシュボード（`https://dashboard.ngrok.com/tunnels/agents`）で定期チェック。切断時はコマンドを再実行して新しいURLを共有。
- **動作確認**  
  - スタッフ端末から `http://localhost:5001` と ngrok URL の両方へアクセスし、カード追加やマーク操作が反映されることを確認。  
  - イベント本番前に複数端末で同時アクセスして遅延やセッション保持をテスト。
- **状態管理**  
  - 150分間操作が無く、かつ `games` 登録数が100を超えたセッションのみ自動削除。通常の進行であればイベント中に状態が失われることはない。  
  - 盤面をリセットしたい場合はフロントの「オールクリア」を実行、またはサーバー側で `games.clear(); last_activity.clear()` を実行。  
  - イベント終了後は Flask / ngrok をそれぞれ `Ctrl+C` で停止し、必要に応じてサーバーを再起動して初期状態へ戻す。
- **トラブルシューティング**  
  - ngrok プロセスが見当たらない場合はタスクマネージャーで「ngrok agent」を確認。  
  - URLへ接続できない場合はPCのネットワーク状態、ファイアウォール例外（TCP 5001）、トンネル再接続状況をチェック。  
  - 緊急時は予備PCに同環境を用意し同手順で立ち上げ直す。

## ゲームルール

### 基本ルール
1. **カード選択**: 利用可能なビンゴカードから選択して追加
2. **数字抽選**: 1-9の数字をクリックで選択
3. **雷トークン**: 数字を±1または±2変更可能（初期4個）
4. **ビンゴ処理**: 確定した数字と同じ数字の盤面をクリックでマーク
5. **ボーナス**: 行・列完成時にボーナス獲得
6. **得点計算**: 完成カード、星マーク、月トークンなどで得点計算

### ボーナス種類
- **数字ボーナス**: 該当数字を自動マーク
- **？ボーナス**: 任意の数字をマーク
- **⚡雷ボーナス**: 雷トークン獲得
- **🌙月ボーナス**: 月トークン獲得（最終得点計算用）
- **⭐星ボーナス**: 星トークン獲得（ラウンド内得点）

## 操作方法

### 基本操作
1. **カード追加**: カードIDを選択して「カード追加」ボタンをクリック
2. **数字選択**: 1-9の数字ボタンをクリック
3. **雷トークン使用**: 必要に応じて雷トークン使用を選択
4. **数字確定**: 「数字確定」ボタンをクリック
5. **ビンゴマーク**: 該当する盤面の数字をクリック

### 操作の取り消し
- **Undo**: 直前の操作を取り消し
- **Redo**: 取り消した操作をやり直し

### トークン管理
- 各トークンの横にある「+」「-」ボタンで手動調整可能
- ボーナス獲得時は自動的に増減

## 技術仕様

### アーキテクチャ
- **バックエンド**: Python Flask（`app.py` は `port=5001` で起動）
- **フロントエンド**: HTML5, CSS3, JavaScript (ES6)
- **セッション管理**: Flask Session (Cookie-based)
- **データ管理**: インメモリ（将来的にCSV/JSON対応予定）

### ファイル構成
```
SuperMegaLuckyBox/
├── app.py                 # メインアプリケーション
├── requirements.txt       # 依存関係
├── README.md             # このファイル
├── templates/
│   └── index.html        # メインページ
└── static/
    ├── css/
    │   └── style.css     # スタイルシート
    └── js/
        └── game.js       # ゲームロジック
```

### API エンドポイント
- `GET /` - メインページ
- `GET /api/game_state` - ゲーム状態取得
- `POST /api/add_card` - ビンゴカード追加
- `POST /api/set_number` - 現在数字設定
- `POST /api/mark_number` - 数字マーク
- `POST /api/undo` - 操作取り消し
- `POST /api/redo` - 操作やり直し
- `GET /api/stats` - サーバー統計
